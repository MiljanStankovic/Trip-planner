Dodaj Putovanja u Claude

Jednom, oko minut. Posle radi na svim uređajima gde si prijavljen u Claude.

  1. Kopiraj svoju adresu

    Napravljena je samo za tebe; po njoj Putovanja znaju šta ti pratiš.

    …
    Ista adresa ostaje kad se vratiš na ovu stranu u ovom pregledaču.
  2. Otvori konektore u Claude-u

    Najlakše na računaru ili u pregledaču. Posle se Putovanja sama pojave i u aplikaciji na telefonu.

    Kopiraj adresu i otvori Claude
  3. Dodaj prilagođeni konektor

    Klikni „Add custom connector”, za ime upiši Putovanja, a za URL nalepi adresu iz koraka 1. Sačuvaj.

  4. Probaj

    U novom razgovoru napiši „Otvori Putovanja” ili „Šta ima za Grčku?”. Prozor se otvara u razgovoru.

Besplatan Claude dozvoljava jedan prilagođeni konektor; ovo je taj jedan.

Imaš Claude Code na računaru?

Putovanja mogu da stoje i kao pano pored razgovora, u terminalu ili u Code delu aplikacije Claude. Ne treba ništa drugo da instaliraš.

  1. U Claude Code pošalji
    /plugin marketplace add MiljanStankovic/Trip-planner
  2. Pa ovo
    /plugin install putovanja@putovanja
  3. Ponovo otvori Claude Code i otkucaj
    /putovanja

    Za praćenje cena i u panou: u /plugin otvori Putovanja, podešavanja, i upiši istu adresu iz koraka 1 gore.

Nemaš Claude Code? Windows (PowerShell): irm https://claude.ai/install.ps1 | iex, Mac ili Linux: curl -fsSL https://claude.ai/install.sh | bash.
