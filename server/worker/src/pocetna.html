Dodaj Putovanja u Claude

Jednom, oko minut. Posle radi na svim uređajima gde si prijavljen u Claude.

  1. Klikni dugme ispod

    Tvoja lična adresa se kopira, a u Claude-u se otvore konektori. Po adresi Putovanja znaju šta ti pratiš.

  2. Dodaj prilagođeni konektor

    Klikni „Add custom connector”, za ime upiši Putovanja, a za URL nalepi adresu. Sačuvaj.

  3. Probaj

    U novom razgovoru napiši „Otvori Putovanja” ili „Šta ima za Grčku?”. Prozor se otvara u razgovoru, i na telefonu.

Najlakše je na računaru ili u pregledaču. Besplatan Claude dozvoljava jedan prilagođeni konektor; ovo je taj jedan.

Putovanja u Claude Code-u

Pano pored razgovora, u terminalu ili u Code delu aplikacije Claude. Ne treba ništa drugo da instaliraš.

  1. U Claude Code pošalji
    /plugin marketplace add MiljanStankovic/Trip-planner
  2. Pa ovo
    /plugin install putovanja@putovanja
  3. Ponovo otvori Claude Code i otkucaj
    /putovanja

Za praćenje cena i u panou: u /plugin otvori Putovanja, podešavanja, i upiši svoju adresu iz izbora „Claude”. Nemaš Claude Code? Windows (PowerShell): irm https://claude.ai/install.ps1 | iex, Mac ili Linux: curl -fsSL https://claude.ai/install.sh | bash.
